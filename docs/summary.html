3ปัญหาที่พบและแนวทางแก้ไข

3.1 พื้นที่ดิสก์เต็มระหว่าง build image ของ Airflow
อาการคำสั่ง docker compose up --build ล้มเหลว (input/output error) จากนั้น Docker daemon หยุดทำงาน และทุกคำสั่งแจ้ง ENOSPC
หาสาเหตุdf -h พบพื้นที่เหลือ 0 B · du -sh พบไฟล์ Docker.raw ขนาด 30 GB · docker system df พบ image ที่ไม่ใช้งาน 7.9 GB
แก้ไขล้าง cache ที่สร้างใหม่ได้ และรัน docker image prune -a กับ builder prune ได้พื้นที่คืน 10.6 GB · เลือกใช้ LocalExecutor และ image เดียวร่วมกันเพื่อลดขนาด
3.2 ไฟล์ Excel ของ ทปอ. แต่ละปีมีโครงสร้างไม่เหมือนกัน
อาการชื่อคอลัมน์คะแนนต่างกันในแต่ละปี (ปี 2569 มีคอลัมน์ "DS" และ "รหัสโครงการ" เพิ่ม) และข้อมูลเขียนทับกันเมื่อ UPSERT
หาสาเหตุเปรียบเทียบ header ของทุกไฟล์ และนับรหัสหลักสูตรที่ซ้ำ (ปี 2569 ซ้ำ 56 รหัส)
แก้ไขเลือกคอลัมน์ด้วยคำสำคัญและใช้ผลการประมวลผลรอบสุดท้าย · กำหนด source_record_id = รหัสหลักสูตร | รายละเอียด | วิชาเอก | รหัสโครงการ
3.3 ชื่อหลักสูตรไม่ตรงกันระหว่างแหล่งข้อมูล
อาการ"น.บ.(นิติศาสตรบัณฑิต)" จาก ทปอ. ไม่ถูกจับคู่กับ "นิติศาสตร์" จาก อว. ทำให้หลักสูตรเดียวกันแยกเป็น 2 แถว
หาสาเหตุค้นหาแถวในตารางสรุปที่พบเพียง 1 แหล่ง (n_sources = 1) แต่ชื่อใกล้เคียงกับแถวอื่น
แก้ไขปรับฟังก์ชัน major_key ให้ใช้ชื่อหลังคำว่า "สาขาวิชา" หรือชื่อปริญญาในวงเล็บ และตัดคำว่า "บัณฑิต" ช่องว่าง และไม้ทัณฑฆาต ทำให้หลักสูตรที่จับคู่ได้ตั้งแต่ 2 แหล่งเพิ่มเป็น 214 หลักสูตร
3.4 ช่องจำนวนรับไม่ใช่ตัวเลข
อาการ44 แถวจาก admission.ku.ac.th ระบุว่า "*จำนวนรับรวมกับเงื่อนไขอื่น" แทนตัวเลข
หาสาเหตุตรวจเหตุผลในตาราง dq_quarantine และเปิด HTML ของหน้าโครงการต้นทาง
แก้ไขเพิ่มกฎตรวจคุณภาพ "ต้องมีจำนวนรับ" และแยกแถวเหล่านี้ออกไม่นำมาคำนวณ เพื่อป้องกันการนับที่นั่งซ้ำ
